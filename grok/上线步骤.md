# 在 Grok Bot 上线「紫微八字命理师」

## 先弄清一件事：代码怎么到 Bot 那里

Grok Bot 不能上传文件或代码包，分享模板时也只会带上 Bot 的身份、描述、**技能**和例行任务，脚本和代码不会跟着走。所以：

- **技能（SKILL.md）是文字**，你粘贴给 Bot 保存，以后分享模板也会带上。
- **排盘程序放在 GitHub 的一个公开 Release 里。** 技能第 0 步写好了下载地址和 SHA256 校验值，Bot 第一次用时会自己下载、校验、安装；别人导入你的模板后，他的 Bot 也会这样自动装好。

所以上线前要先做一次「发布」（下面第 1 步）。之后每次更新程序，都要重新发布，并把新的技能文字发给 Bot。

## 1. 发布程序（只需要做一次，更新时再做）

1. 在 GitHub 新建一个**公开**仓库，比如 `ziwei-bazi-bot`，把这个文件夹里的内容推上去。
2. 运行发布脚本，生成压缩包、校验值，以及填好下载地址的技能文字：
   ```bash
   python3 tools/make_release.py --repo 你的用户名/ziwei-bazi-bot
   ```
3. 在仓库的 Releases 里新建版本 `v1.1.0`，把 `dist/` 里的 `ziwei-bazi-report-1.1.0.zip` 和 `SHA256SUMS.txt` 上传上去。
4. 之后要粘贴给 Bot 的技能文字，是 `dist/SKILL.md`。它和仓库里那份不同，这一份已经填好了下载地址和校验值。

> 也可以把仓库地址告诉 Claude，让它帮你推送代码和发布。

## 2. 新建 Bot

1. 点侧边栏顶部的 **+**（或按 `Cmd/Ctrl + N`）。
2. 名字填「紫微八字命理师」，选一个头像，点 **Create**。
3. 想换头像，可以在 Bot 详情里上传 `avatar.png`（要小于 25 MB）。

## 3. 设定职责

把 `grok/BOT说明.md` 两条虚线之间的内容作为第一条消息发给 Bot，让它记住。

## 4. 添加技能

发给 Bot：

> 把下面这段内容保存为你的技能，名字叫 ziwei-bazi-report，以后排盘、看运势、合盘都按它做。保存后按技能的第 0 步安装并运行自检，把自检结果告诉我。

然后把 `dist/SKILL.md` 的全文粘贴在后面。

自检应该显示「完全一致，0 张有差异」和「故意写错的 5 处抓到 5 处」。

## 5. 试运行

按顺序试几件事，确认 Bot 每一步都照做：

| 试什么 | 发给 Bot | 应该看到 |
|---|---|---|
| 正常排盘 | 帮我排盘：公历 1990 年 5 月 20 日下午 2 点 30 分，女，杭州 | 先报核对结果，提到夏令时但说明盘不变，然后给结论和报告 |
| 需要确认 | 帮我排盘：公历 1988 年 8 月 8 日早上 8 点 8 分，男，北京 | 先问你出生时间是不是当时的钟表时间（夏令时会改变时辰） |
| 追问流月 | 那这个月怎么样？ | 八字流月和紫微流月各一句，再给综合提示 |
| 合盘 | 再排一个人，然后帮我们合盘 | 两人分别排盘后给合盘结论，不打分、不说「配不配」 |
| 时间不确定 | 我只知道大概是下午 3 点左右出生 | 列出相邻两个时辰的差别，问你几件往事 |
| 删除数据 | 删除我的数据 | 确认已删除 |

## 6. 分享成模板

1. 点 Bot 名字，选 **Share → Create a copy**，再点 **Publish → Copy link**。手机上用 Bot 菜单里的 **Share as Template**。
2. 别人打开链接点 **Import Bot / Add to Grok Bot**，或在侧边栏 **Connect apps → Bot templates** 里导入。导入的是一份副本，第一次排盘时他的 Bot 会按技能第 0 步自动装好程序。
3. **公开链接谁拿到都能打开。** 这个技能里没有密钥、内部地址或个人资料；发布前再看一眼技能文字和 Bot 说明，别把自己的出生信息写进去。
4. 团队版的管理员可以限制或关闭公开模板。网上说的「Bot 市场」目前没有找到官方上线的证据。

## 7. 更新版本

改了程序后：改版本号 → 运行 `tools/make_release.py` → 在 GitHub 发布新版本 → 把新的 `dist/SKILL.md` 发给 Bot，替换原来的技能 → 重新发布模板。旧版本的 Release 不要删，已经导入旧模板的人还在用它。

## 上线前注意

- **平台规则：** 公开发布前看一下 xAI 对算命类内容的使用政策。
- **数据许可：** 报告会自动写上开源数据集的来源（CC BY 4.0 要求署名），不要删。数据集正文引用的倪海厦原话仅限非商业用途；如果收费，就不要在报告里转引这些原话。
- **隐私：** 出生时间加出生地属于敏感的个人信息。Bot 说明里已经要求它不写进长期记忆、用户要求时立刻删除。
- **免责：** 报告结尾的免责说明请保留。
